# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common questions to get you started engaging with this project in
[our documentation](https://github.com/changesets/changesets/blob/main/docs/common-questions.md)

## How to Use Changesets in This Project

### For Contributors

When you make changes that should be documented in the changelog (new features, bug fixes, breaking changes):

1. **Create a changeset**:
   ```bash
   npm run changeset
   ```
   or
   ```bash
   npx changeset
   ```

2. **Follow the prompts**:
   - Select which packages are affected (server, mobile, or both)
   - Choose the change type:
     - **patch**: Bug fixes and minor updates (1.0.0 → 1.0.1)
     - **minor**: New features, backward compatible (1.0.0 → 1.1.0)
     - **major**: Breaking changes (1.0.0 → 2.0.0)
   - Write a summary of your changes

3. **Commit the changeset file** along with your code changes

### For Maintainers

When ready to release new versions:

1. **Version the packages**:
   ```bash
   npm run changeset:version
   ```
   This will:
   - Consume all changeset files
   - Update package versions
   - Generate/update CHANGELOG.md files

2. **Review the changes**:
   - Check the updated versions in package.json files
   - Review the generated CHANGELOG.md files

3. **Commit and push**:
   ```bash
   git add .
   git commit -m "chore: version packages"
   git push
   ```

4. **Publish** (if applicable):
   ```bash
   npm run changeset:publish
   ```

## Example Changeset File

```markdown
---
"mobile": minor
"server": patch
---

Add new timer preset feature

- Users can now create and save timer presets
- Fixed bug in timer synchronization
- Improved WebSocket connection stability
```
